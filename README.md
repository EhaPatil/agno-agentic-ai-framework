# Agentic AI Development Using Agno

## Project Overview

This project focuses on developing intelligent AI agents and collaborative multi-agent systems using the **Agno framework**. It explores how Large Language Models (LLMs) can be integrated with external tools to retrieve information, perform specialized tasks, and coordinate multiple agents.

The project follows a progressive development approach, starting with basic AI agents and advancing toward tool-enabled agents, multi-agent collaboration, and knowledge-based AI systems.

## Project Objectives

- Understand the fundamentals of Agentic AI and agent-based architectures.
- Develop AI agents using the Agno framework.
- Integrate Groq-hosted LLMs for intelligent response generation.
- Enable real-time information retrieval through external tools.
- Implement multi-agent collaboration and task delegation.
- Explore Retrieval-Augmented Generation (RAG) for document-based knowledge retrieval.

## Implemented Features

### 1. Basic AI Agent
Developed an AI agent using Agno and Groq-hosted LLMs to understand user queries and generate relevant responses.

### 2. Tool-Enabled AI Agent
Extended the basic agent with DuckDuckGo web search, enabling it to retrieve external information and generate more contextually relevant responses.

### 3. Multi-Agent Research System
Developed a collaborative system consisting of three components:

- **Web Agent:** Retrieves relevant information and recent developments through internet search.
- **Finance Agent:** Retrieves company information, stock prices, and financial data.
- **Team Leader:** Coordinates specialized agents, delegates tasks, and consolidates their findings into a unified response.

## Key Learnings

- Understanding the difference between LLM-based chatbots and tool-enabled AI agents.
- Integrating external tools with AI agents.
- Designing specialized agents with distinct responsibilities.
- Implementing task delegation and coordination through multi-agent systems.
- Understanding the role of LLMs in agent decision-making.
